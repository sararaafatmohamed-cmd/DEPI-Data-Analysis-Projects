# 🌍 Country Development & Economic Performance Analysis

## 📌 Project Overview

This project explores country-level data to analyze economic performance, population distribution, health indicators, and regional development using **Microsoft Power BI**.

Developed as part of the **Digital Egypt Pioneers Initiative (DEPI)**, the project transforms raw data into interactive dashboards to support comparisons across countries and regions.

## 🎯 Project Objectives

- Analyze GDP and GDP per capita across countries.
- Compare population size and regional distribution.
- Explore health indicators, including life expectancy, birth rate, death rate, and infant mortality.
- Evaluate economic growth, inflation, imports, and exports.
- Identify differences in economic and development indicators across countries and regions.

## 🛠️ Tools & Technologies

- **Power BI** — Interactive dashboards and data visualization.
- **Power Query** — Data cleaning and transformation.
- **DAX** — Measures, KPIs, and analytical calculations.
- **Data Modeling** — Organizing data for interactive analysis.

## 📊 Dashboard Pages

### 1. Executive Overview
Provides a high-level overview of country development through key performance indicators, GDP comparisons, population distribution, and regional analysis.

### 2. Health Analysis
Explores health indicators such as life expectancy, birth rate, death rate, and infant mortality, with comparisons across countries.

### 3. Economic Performance Analysis
Examines imports, exports, inflation, and economic growth to compare economic performance across countries and regions.

## ⚙️ Key Features

- Interactive KPI cards and data visualizations.
- Country and region filtering using slicers.
- DAX measures for analytical calculations.
- Dynamic dashboard titles.
- Drill-through navigation for country-level analysis.
- Conditional formatting to highlight indicator differences.
- Interactive filtering between visuals.
