
# 👥 HR Analytics Dashboard – Power BI

A Power BI dashboard project focused on analyzing employee data and exploring key HR metrics and workforce trends.

## 📌 Project Overview

The dashboard provides an interactive view of HR data to explore employee demographics, workforce distribution, and key HR indicators.

## 📊 Analysis Areas

* 👥 Employee Overview
* 📈 Employee Distribution
* 🚻 Gender Analysis
* 🎂 Age Analysis
* 💼 Department Analysis
* 📅 Hiring Trends
* 📊 HR Key Metrics

## 🛠️ Tools

* Power BI
* Power Query

## 📁 Files

* `HR Analytics Dashboard.pbix` – Power BI dashboard
* `HR-Analytics.png` – Dashboard preview
