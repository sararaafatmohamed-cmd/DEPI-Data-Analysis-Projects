# Superstore 2019 – Sales Analysis Dashboard

## Overview

A sales analysis project built using the Superstore 2019 dataset in Microsoft Excel.

The project focuses on analyzing sales and profit performance and presenting key business insights through an interactive Excel dashboard.

## Tools

* Microsoft Excel
* Power Query
* Power Pivot

## Data Preparation

The data was cleaned and prepared using Power Query before building the data model.

The project uses a structured data model to organize the main business entities and their relationships.

## Data Model

The model includes:

* Orders
* Customers
* Products
* Categories
* Locations
* Order Date
* Ship Date
* Returns

## Dashboard

The dashboard provides an overview of sales performance through:

* Total Orders
* Total Sales
* Total Profit
* Number of Products
* Monthly Sales Analysis
* Product Sales Analysis
* Category Analysis
* Regional Analysis

## Key Insights

* High Speed Automatic Electric Letter Opener had the highest sales at **$17,030.31**.
* **November** recorded the highest monthly sales at **$352,461**.
* **February** recorded the lowest monthly sales at **$59,751**.
* **Labels** generated the highest share among the categories.

## Project Objective

The objective of this project was to transform raw sales data into a structured and interactive Excel dashboard that provides clear insights into sales performance and supports business analysis.

## Deliverable

**Interactive Excel Sales Dashboard**

The final deliverable includes the cleaned data, data model, and dashboard developed in Excel.
