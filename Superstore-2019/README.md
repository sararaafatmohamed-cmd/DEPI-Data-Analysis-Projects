# Superstore 2019 – Power BI Sales Dashboard

## Overview
A sales analysis project using the Superstore 2019 dataset, developed as a mock freelance Power BI task.

## Tools
- Power BI
- Excel
- Power Query

## Project Focus
The dashboard focuses on:
- Sales performance
- Profit performance
- Product performance
- Category analysis
- Regional analysis
- Monthly sales trends

## Dashboard KPIs
- Total Orders
- Total Sales
- Total Profit
- Number of Products

## Key Insights
- High Speed Automatic Electric Letter Opener had the highest sales at $17,030.31.
- November recorded the highest monthly sales at $352,461.
- February recorded the lowest monthly sales at $59,751.
- Labels generated the highest share among the categories.

## Deliverable
An interactive Power BI dashboard designed to provide a clear overview of sales performance and support business analysis.
